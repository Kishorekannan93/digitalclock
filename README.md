# 📖 Overview

Digital Clock is a lightweight web application that displays the current system time and updates automatically every second.

The project was created to practice JavaScript timing functions, DOM manipulation, and responsive UI design using core web technologies.

---

# ✨ Features

- 🕒 Live Digital Clock
- ⏱ Real-time Time Updates
- 🎨 Clean & Minimal UI
- 📱 Responsive Design
- ⚡ Lightweight & Fast
- 🌐 Runs Directly in Browser

# 🚀 How It Works

1. Open the application in your browser.
2. The current system time is displayed.
3. JavaScript updates the clock every second.
4. No page refresh is required.
